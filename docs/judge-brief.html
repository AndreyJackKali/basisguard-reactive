Why Track 1 ("Every Second Counts") Fit

  • Zero Off-Chain Keepers: Eliminates centralized bots, cron polling, and RPC rate-limit failure during flash crashes.
  • Sub-2-Second Target Loop: Base Sepolia (~200ms) + Reactive Lasna (~1s CometBFT) + Callback Proxy relay.
  • Emergency Liquidation Bypass: Normal actions respect per-vault cooldowns (15s), but extreme liquidation danger (HF < 1.05x) bypasses cooldown immediately.
  • Clean Gas-Saving Suppressions: Below-threshold, replay, cooldown, and breaker events emit ReactionSuppressed instead of reverting.

Why reactive-lib-omni 2026 SDK Matters

  • Non-Deprecated Callbacks: Calls SYSTEM.requestCallbackV_1_0(CallbackConfiguration_V_1_0) instead of deprecated emit Callback(...).
  • 160-Bit Sender Injection: Reserves arg0 = address(0) in executeProtection so the official Callback Proxy overwrites it with BasisGuardReactive's immutable identity.
  • Full Reactive Economy Support: Implements pay() / coverDebt() + dynamic pause() / unpause() subscription lifecycle.
  • Honest Verification: MockSystemContract etched at 0x8888...8888 in Foundry; zero fabricated testnet TX hashes.
